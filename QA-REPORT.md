## 1. Build — `npm run build` ❌ FAIL

Full output:

```
> playzone-esports@1.0.0 build
> next build

 ⨯ Failed to load next.config.ts, see more info here https://nextjs.org/docs/messages/next-config-error

> Build error occurred
[TypeError: Cannot read properties of undefined (reading 'fileExists')]
```

**Root cause (verified, not guessed):**
- `package.json` pins `typescript: ^7.0.2` (installed: 7.0.2). This major (the native-port line) is unsupported by Next 15.5.28.
- Next 15.5.28's config loader (`node_modules/next/dist/build/next-config-ts/transpile-config.js` → `getTsConfig()`) calls `ts.findConfigFile(cwd, ts.sys.fileExists, 'tsconfig.json')` and `ts.parseJsonConfigFileContent(configFile.config, ts.sys, cwd)`.
- In TypeScript 7.0.2, `ts.sys` is `undefined` and `ts.findConfigFile` is `undefined` (verified via `node -e` require). Hence `Cannot read properties of undefined (reading 'fileExists')`.
- `next.config.ts` content itself (`import type { NextConfig } from "next"; …`) is valid — the failure is purely the TS7 vs Next 15.5 toolchain incompatibility.
- The build dies before compilation, so the `next/font/google` (Black_Ops_One, Rajdhani in `app/layout.tsx`) network fetch could not be evaluated — it was never reached.
